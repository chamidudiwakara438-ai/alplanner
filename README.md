# AL Planner — Sri Lankan A/L Learning Platform

A complete, full-stack learning platform for G.C.E. **A/L Chemistry, Combined Mathematics and Biology** students: video lessons, notes, past papers, student uploads with admin approval, progress tracking, a tutor marketplace, and a full admin control room — wrapped in a premium 3D glass UI in **English, Sinhala and Tamil**.

## Quick start

The backend is a single **Node.js (Express)** runtime:

```bash
cd al-planner
npm install
npm start                # → http://localhost:3000
```

(Or just double-click `start-windows.bat` / run `./start-mac-linux.sh` — they install
dependencies on first run and then start the site.)

The database (SQLite) is created and seeded automatically on first run into `data/`,
with uploads in `uploads/`, including real PDF study materials and video lessons.

### Loading the full content library

The seed gives you a working site; the **full lesson library** (Chemistry, Physics,
Combined Maths video packs, lesson Theory/MCQ tabs and syllabus links) is applied by
one command after the site has been started once:

```bash
npm run content          # applies everything, in order
```

Every step is **idempotent** — run it as often as you like, already-present lessons are
skipped. Individual packs can be run on their own:

| Command | What it does |
|---|---|
| `npm run content:clean-demo` | Removes demo lessons, fake teachers and demo tutors |
| `npm run content:subjects` | Adds Physics + ICT with their official NIE unit lists |
| `npm run content:cm-units` | Replaces the CM placeholders with the 19 official topic units |
| `npm run content:chemistry` | Chemistry unit restructure + video lesson pack |
| `npm run content:cm-lessons` | Combined Maths video lessons |
| `npm run content:physics` | Physics bilingual units + main video pack |
| `npm run content:physics2` / `:physics3` | Physics video lesson batches 2 and 3 |
| `npm run content:tabs` | Lesson **Theory** + **MCQ questions** tabs |
| `npm run content:links` | Syllabus / past-paper external link resources |

The lesson data itself lives as plain JSON in **`content/`**, so you can add videos or
links by editing a JSON file and re-running the matching command — no code changes
needed. The scripts that apply them are in **`scripts/`**.

## Architecture

```
al-planner/
├── server.js            Express 4 API (auth, sessions, uploads, admin, SPA host)
├── db.js                SQLite schema (better-sqlite3, WAL, FK cascades) + shared constants
├── seed.js              Idempotent seed: users, 3 subjects, 8 units, 24 lessons, 13 PDF resources,
│                        7 teachers, 6 tutors, A/L years, demo progress   (npm run reseed to reset)
├── pdfgen.js            Zero-dependency PDF writer used for seed study materials
├── data/                alplanner.db (auto-created)
├── uploads/             Resource files (seed-* + u-* user uploads) — served only via auth-checked
│                        /api/resources/:id/download (pending files stay private)
└── public/
    ├── index.html       App shell (fonts, aurora, mounts)
    ├── css/style.css    Design system (glass, 3D, responsive, bottom nav)
    ├── js/i18n.js       EN / SI / TA dictionaries
    ├── js/app.js        SPA: hash router, all views, 3D effects, admin UI
    └── assets/tutors/   Tutor profile photos
```

### Data model

`users(name, email, password, role, school, district, al_year, medium, stream, subjects)` · `al_years` · `subjects(name, name_si, name_ta, medium, colors, icon)` · `units(subject, name)` · `lessons(unit, teacher, title, video, notes…)` · `teachers` · `resources(title, file, category, subject, lesson, uploaded_by, status)` · `tutors(name, photo, subjects, profile, contact)` · `tutor_messages` · `progress(user, lesson, completed, watched, favourite)` · `saved_resources` · `sessions`

### Extension points (built for the roadmap)

- **Premium subscriptions & payments** — `users.role` is already a flexible field (add `plan`/`plan_expires`), and premium gating can reuse the same auth middleware pattern as `requireAdmin`.
- **AI learning assistant** — lessons carry structured context (subject/unit/title/notes) ready to feed a chat endpoint.
- **Mobile app** — the entire UI is an API-driven SPA (`/api/*` JSON everywhere, cookie auth → easy token swap), so a React Native/Flutter client can reuse every endpoint.

## Security notes

- Bcrypt password hashing, httpOnly + SameSite=Lax session cookies, sessions stored server-side with expiry.
- Upload allowlist (pdf/doc/ppt/txt/md/zip/images, 25 MB), randomised stored filenames, downloads permission-checked (approved / owner / admin only).
- All dynamic HTML is escaped client-side; SQL uses parameterised statements throughout.

## Reset the demo data

```bash
npm run reseed     # wipes and re-seeds the database (uploads folder keeps files)
```
